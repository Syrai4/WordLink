# WordLink 🧩 - Inspired by wordle

**Four clues. One connection. Can you find it?**

WordLink is a daily word association game that challenges players to uncover the hidden connection between four clues. Players use logic, vocabulary, pattern recognition, and critical thinking to figure out what links the words together.

Inspired by the fun of daily word puzzles, WordLink puts a creative spin on word association by encouraging players to think beyond the obvious and discover connections they might otherwise overlook.

🌐 **Play WordLink:** https://wordlink-alpha.vercel.app/

## 🎮 How to Play

1. Read the four clues presented in the puzzle.
2. Think about what word, theme, or idea connects all four clues.
3. Enter your answer and submit your guess.
4. Use the feedback to help guide your next attempt.
5. Solve the puzzle within four attempts!

Each puzzle is an opportunity to challenge your thinking and make connections in a new way.

## ✨ Features

- **Daily Puzzles:** A new word connection challenge each day.
- **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard.
- **Four Attempts:** Test your reasoning with a limited number of guesses.
- **Hints:** Get a little help when you need it.
- **Player Statistics:** Track games played, wins, current streak, and best streak.
- **Responsive Design:** Play on desktop, tablets, and mobile devices.
- **Feedback Form:** Share suggestions and report issues directly with the developer.

## 🚀 Getting Started

Want to run WordLink locally?

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Syrai4/WordLink.git
```

Navigate into the project:

```bash
cd WordLink
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
